# Changelog

## 0.1.1 — 2026-09-21

- Added first-class CommonJS builds for the root, CAS, and app entry points.
- Added conditional `import`/`require` exports while preserving ESM support.
- Added regression tests that load every code entry point through both module systems.

- Added non-executable 40-condition research registry.
- Added tests, CI, contribution policy, audit report, and publishing runbook.
