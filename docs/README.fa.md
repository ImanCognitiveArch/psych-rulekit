# راهنمای فارسی PsychRuleKit

`PsychRuleKit` یک موتور قانون‌محورِ شفاف و قطعی برای نرم‌افزارهای پژوهشی سلامت
روان است. موتور، داده‌ی ارزیابی و بسته‌ی قواعد از یکدیگر جدا هستند؛ بنابراین
می‌توان هر بخش را مستقل نسخه‌بندی، بازبینی و آزمایش کرد.

این پروژه «کتابخانه‌ی رسمی DSM» نیست و هیچ متن معیار تشخیصیِ دارای حق نشر را
منتشر نمی‌کند. خروجی نیز تشخیص نیست؛ فقط نشان می‌دهد داده‌های ساختاریافته‌ی
ورودی با یک بسته‌ی قواعد مشخص چه نسبتی دارند.

## دلیل کنارگذاشتن ساختار اولیه

ساختار اولیه‌ی `min_symptoms_required + duration_required_weeks` برای نمایش
قواعد بالینی پیچیده کافی نبود. برای نمونه نمی‌توانست تفاوت این حالت‌ها را
نشان دهد:

- حضور همه‌ی معیارها در برابر حضور یکی از آن‌ها؛
- حداقل تعداد از چند خوشه‌ی مستقل؛
- شرط‌های وابسته به سن یا زمینه؛
- چند بازه‌ی زمانی متفاوت؛
- شرطِ الزامی در برابر معیار ردکننده؛
- اطلاعات «نامعلوم» در برابر پاسخ منفی.

ساختار جدید از درخت قواعد و منطق سه‌حالته استفاده می‌کند و برای هر نتیجه یک
ردیابی توضیح‌پذیر می‌سازد.

## پیشنهاد انتشار

ترکیب حرفه‌ای این است:

1. `GitHub` برای کد، مشارکت، بازبینی و نسخه‌ها؛
2. `npm` برای نصب مستقیم در اپ‌های `TypeScript/React Native`؛
3. `Zenodo` برای آرشیو نسخه و دریافت `DOI` قابل استناد.

پایگاه ۴۰ اختلال فعلاً فقط به‌شکل فهرست دامنه نگهداری شده است. افزودن قواعد
اجرایی برای هر مورد منوط به بررسی منبع، مجوز بازنشر، بازبینی بالینی مستقل و
تست است.

## اتصال به اپ

```ts
import {
  evaluateRulePack,
  toAppEvaluationRecord,
} from "psych-rulekit";

const evaluation = evaluateRulePack(rulePack, { facts });
const record = toAppEvaluationRecord(evaluation);
```

خروجی اپ شامل نتیجه، نسخه‌ی بسته و شناسه‌ی داده‌های ناقص است؛ روایت خام یا
اطلاعات هویتی را ذخیره نمی‌کند. در اپ‌هایی با هویت غیرتشخیصی، این قابلیت باید
در یک بخش پژوهشی مستقل و همراه با هشدار واضح نمایش داده شود.
