# Rule-pack review checklist

## Rights and provenance

- [ ] Exact source edition and locator recorded for every rule.
- [ ] Redistribution permission or open license documented.
- [ ] Trademarks and attribution handled without implying endorsement.

## Logic extraction

- [ ] Two independent extractions completed.
- [ ] Disagreements adjudicated and recorded.
- [ ] Required conditions are not encoded as exclusions.
- [ ] `all`, `any`, per-cluster counts, and conditional thresholds are explicit.
- [ ] Minimum and maximum time bounds use exact units.
- [ ] Age, setting, course, impairment, and differential conditions are explicit.

## Testing

- [ ] Positive fixture.
- [ ] Negative fixture for every mandatory gate.
- [ ] Exact boundary fixtures.
- [ ] Exclusion fixtures.
- [ ] Missing-data fixtures that must return `insufficient_information`.
- [ ] Regression fixtures for every corrected extraction error.

## Review and claims

- [ ] Clinical review documented.
- [ ] Methodological review documented.
- [ ] Locale and jurisdiction declared.
- [ ] Intended use and prohibited uses declared.
- [ ] Validation evidence matches every public claim.
